# Security Policy

Report security issues privately to the repository owner before public disclosure.

Do not open a public issue for secrets, token leaks, credential exposure, or vulnerabilities that could put users at risk.

## Scope

Security reports may include:

- Installer behavior that writes outside the intended skill directory.
- Accidental inclusion of secrets or private traces.
- Unsafe automation inside skill scripts.
- Instructions that encourage destructive actions without confirmation.

## Handling

The maintainer will review reports, remove exposed data when needed, and publish a fix or advisory when appropriate.
