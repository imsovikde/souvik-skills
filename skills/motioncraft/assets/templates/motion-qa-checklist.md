# Motion QA Checklist

- [ ] Product archetype and emotional tone are stated.
- [ ] Motion intent map exists for changed surfaces.
- [ ] Every major animation has a psychological job.
- [ ] Motion tokens are centralized and reused.
- [ ] Direct feedback starts within 50 ms.
- [ ] Repeated product interactions complete in 80-220 ms.
- [ ] Shared elements preserve continuity where needed.
- [ ] Reduced-motion mode is tested, not only written.
- [ ] Keyboard users can operate menus, drawers, tabs, copy actions, and route changes.
- [ ] Focus rings remain visible and focus returns after overlays close.
- [ ] No `transition: all` is shipped.
- [ ] No hot-path animation uses width, height, top, left, margin, or padding.
- [ ] Offscreen ambient motion pauses or does not exist.
- [ ] Mobile layout has no horizontal overflow or overlapping text.
- [ ] DevTools does not show obvious layout thrash, dropped frames, or animation-caused long tasks.
