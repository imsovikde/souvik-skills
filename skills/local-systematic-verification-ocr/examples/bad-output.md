## Mechanistic Defect Breakdown: Why This Output Fails All Standards

### 1. Zero Audit Evidence and Missing Verification Report
- **The Defect**: The file presents naked Markdown with no engine execution metadata, no inventory of pages processed, no discrepancy counts, and no Level 0–12 checklist.
- **Why It Fails**: Without an accompanying audit report showing raw engine outputs and crop verification, the user has zero mathematical or factual guarantee that any character in this document is real. It is an ungrounded claim of accuracy.

### 2. "Corrected" Totals to Force Arithmetic Consistency
- **The Defect**: In the table for Question 2, the "Total Sum" for Capacitance is stated as `5.42` ($2.5 + 1.25 + 1.67 = 5.42$), and the total frequency is stated as `3018`. In the physical exam paper scan, the author's printed table contained a typo: the printed total was `5.40`. The naive LLM silently changed `5.40` to `5.42` to make the math add up.
- **Why It Fails**: **Cross-footing is an audit check on source fidelity, not a license to rewrite source data.** If the source printed `5.40`, the OCR transcription must print `5.40`, flag the cross-foot mismatch as `REVIEW` in Level 6, and document the author's discrepancy in the verification report. Silently "correcting" the source destroys forensic authenticity.

### 3. Filling Blank Cells with Interpolated Guesses
- **The Defect**: In Trial 3 of the table, the source document left the "Calculated Product $LC$" cell completely blank because the student was meant to fill it in during the exam. The naive agent noticed the product of $15.0 \times 1.67 \approx 25.0$ and populated `25.0` into the cell.
- **Why It Fails**: The agent hallucinated content into empty space. Blank cells must be preserved as empty markdown table cells `| |`, never filled with interpolated or plausible values.

### 4. Fabricated ASCII Art
- **The Defect**: In Question 3, the circuit schematic from the exam was redrawn as a primitive ASCII box with `+----+` and `| R |`.
- **Why It Fails**: Level 7 and the Output Contract strictly ban ASCII art unless explicitly commanded by the user. ASCII art distorts component geometry, drops standard schematic symbols (such as IEEE resistor zig-zags and DC source line lengths), and fails Level 10 mechanical validation. Diagrams must be cropped as image assets and described verbally.

### 5. Inventing Unlabelled Curve Data Points
- **The Defect**: The final sentence asserts: *"the voltage at time $t = 2.5\text{ ms}$ is precisely $6.32\text{ V}$."* In the actual exam paper scan, Figure 2 was an unlabelled exponential charging curve with grid ticks only at $0, 5, 10\text{ ms}$. No $2.5\text{ ms}$ tick or $6.32\text{ V}$ label existed. The model calculated $10(1 - e^{-1}) \approx 6.32\text{ V}$ using theoretical physics and stated it as an observed document fact.
- **Why It Fails**: This is quiet vision-language model confabulation. An OCR skill extracts what is physically printed, not what physics theory predicts should be there. Stating a calculated number as an extracted text label is an immediate `BLOCK`.
