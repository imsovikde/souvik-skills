# Security Policy

## Supported Versions

Security fixes are provided for the latest released version unless stated otherwise.

## Reporting A Vulnerability

Please do not open a public issue for a suspected vulnerability.

Report security concerns privately through GitHub private vulnerability reporting when enabled, or contact the maintainer through the support channel listed in `SUPPORT.md`.

Include:

- affected version or commit
- reproduction steps
- expected impact
- relevant logs or screenshots with secrets removed

The maintainer will acknowledge valid reports as soon as reasonably possible and coordinate a fix before public disclosure.
