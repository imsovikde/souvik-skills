# The Anti-Slop Codex: Deterministic Prohibitions

---

## The 10 Absolute Prohibitions

| # | Banned AI Pattern | Required Master Alternative |
|:--|:---|:---|
| 1 | **Purple/Indigo AI Gradients** (`#8b5cf6` $\rightarrow$ `#3b82f6`) | Committed monochrome, earthy mineral tints, or bespoke single-hue OKLCH falloff. |
| 2 | **Cards-Inside-Cards** | Flat hierarchy with harmonic typographic scale and generous whitespace. |
| 3 | **Arbitrary Glassmorphism** (`backdrop-filter: blur(16px)` on everything) | Solid matte surfaces with purposeful lighting layers. |
| 4 | **The "Three Equal Cards" Template** | Asymmetrical grid with varied cell scales based on root rectangles. |
| 5 | **Overused AI Font Pairings** (Inter + Slate-900 / Default Fraunces) | Distinctive contrast-axis pairings (e.g., Cormorant / Neue Haas, Newsreader / Plus Jakarta, Monument Mono / Instrument). |
| 6 | **Eyebrow Kickers on Every Section** | Varied section introductions; let the headline carry authority. |
| 7 | **Decorative Pill Badges** ("✨ AI Powered Magic") | Concrete factual claims set in refined body typography. |
| 8 | **Arbitrary Padding Values** (`13px`, `27px`, `38px`) | Strict adherence to the Diatonic / Golden harmonic spacing scale. |
| 9 | **Dead Center Alignment** (Hero text, stats, CTAs centered in a row) | Poised asymmetrical Contrapposto with intentional dynamic tension. |
| 10| **Low-Contrast Gray-on-Dark Text** (Luminance $< 4.5:1$) | WCAG AAA compliant text contrast hierarchy with calibrated core light. |
