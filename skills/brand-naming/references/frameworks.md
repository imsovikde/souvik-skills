## 1. SMILE & SCRATCH Framework

> "A name should make you smile instead of scratch your head. If it makes you scratch your head, scratch it off the list." — Alexandra Watkins, *Eat My Words*

### SMILE: 5 Qualities of a Great Name

| Letter | Quality | Description | Iconic Example |
|--------|---------|-------------|---------------|
| **S** | Suggestive | Evokes something about the brand without stating it literally | Amazon suggests vastness and endless selection |
| **M** | Memorable | Creates an association with something familiar | Apple connects to something everyone knows |
| **I** | Imagery | Aids memory through evocative mental pictures | Jaguar creates an immediate, vivid image |
| **L** | Legs | Lends itself to extended wordplay, campaign mythology | Nike allows "Just Do It" mythology to build |
| **E** | Emotional | Moves people; resonates positively with the target audience | Patagonia evokes adventure and wild places |

**"Legs" explained in full:** A name should provide "a theme with mileage you can build a brand around." Test: Can the founding team generate 10 campaign concepts from this name without forcing it?

### SCRATCH: 7 Deal-Breakers (Eliminate Immediately)

| Letter | Deal-Breaker | Red Flag | Example of Failure |
|--------|--------------|----------|--------------------|
| **S** | Spelling Challenged | Looks like a typo; guessing game on first contact | Misspellings without phonetic logic |
| **C** | Copycat | Sounds like an existing brand; confusion risk | "Faceblock" for a social platform |
| **R** | Restrictive | Limits future growth; traps the brand in one category | Boston Market couldn't expand beyond Boston |
| **A** | Annoying | Forced, excessive, or precious wordplay | Names that try too hard to be clever |
| **T** | Tame | Flat, uninspired, purely descriptive | "Best Tech Solutions" |
| **C** | Curse of Knowledge | Meaningful only to insiders; opaque to everyone else | Internal jargon acronyms launched externally |
| **H** | Hard to Pronounce | If people avoid saying it, they avoid the brand | Names with ambiguous vowel clusters |

**Scoring rubric:** Each name starts at 10/10. Deduct 1.5 points per SCRATCH flag triggered, 2 points for S, C (copycat), or H flags (most damaging). Names scoring below 6/10 after SCRATCH filtering should be eliminated.

## 2. Sound Symbolism / Phonosemantics

Sound shapes perception before meaning registers. Phonemes carry subconscious psychological signals that run beneath rational evaluation.

### Phonosemantic Signal Table (Lexicon / Placek methodology)

| Sound / Class | Psychological Signal | Category Applications | Iconic Examples |
|---------------|----------------------|-----------------------|-----------------|
| **V** | Vibrant, alive, fast | Performance, automotive, tech | Corvette, Vercel, Viagra |
| **B** | Reliable, solid, grounded | Finance, enterprise, infrastructure | BlackBerry, Bloomberg |
| **Z** | Attention-getting, energetic, exotic | Consumer, fashion, disruptive tech | Azure, Zara, Zoom |
| **X** | Innovative, unknown, frontier | Deep tech, science, exploration | Xerox, SpaceX, Xbox |
| **K / hard C** | Memorable, crisp, decisive | Consumer products, brand mnemonics | Coca-Cola, Kodak, Kellogg's |
| **P** | Precision, punctual, plosive punch | Professional services, tools | PayPal, Pinterest |
| **Plosives (b, c, k, p, t)** | High memorability, stickiness | Any category where recall matters | Kodak, Coca-Cola, TikTok |
| **Soft sounds (l, m, n)** | Approachable, smooth, friendly | Consumer wellness, lifestyle, luxury | Lululemon, Amazon, LinkedIn |
| **Long vowels (ee, oo)** | Broad, expansive, premium | Luxury, tech, lifestyle | Google, YouTube, Hulu |
| **Short vowels** | Quick, efficient, direct | Utilities, tools, B2B | Slack, Snap, SAP |
| **Rhyme / repetition** | Stickiness, recall, playfulness | Consumer brands, children's | Coca-Cola, TikTok, Chupa Chups |
| **Fricatives (f, s, sh)** | Soft, flowing, whispery | Wellness, spa, luxury | Sofitel, Sephora |

### Phonosemantic Scoring Protocol

For each name candidate:
1. Identify the dominant phoneme class(es)
2. Map the signal(s) to the brand's intended emotional territory
3. Score alignment 1–5: 5 = perfect match, 1 = contradiction
4. Flag any phonosemantic contradictions (e.g., hard plosives for a spa brand)

## 3. The Naming Matrix

Position every name on two axes:

**Axis 1 — Approach** (what the name communicates):
- **Descriptive**: States what the product does (General Motors, TripAdvisor)
- **Suggestive**: Implies what the brand stands for without stating it (Amazon, Slack, Netflix)
- **Abstract**: Carries no inherent meaning — meaning is built through branding (Xerox, Kodak, Häagen-Dazs)

**Axis 2 — Construct** (how the name is built):
- **Real-Word**: Existing word used in a new context (Apple, Amazon, Slack)
- **Compound**: Two real words joined (YouTube, Snapchat, Facebook)
- **Coined**: Invented word or deliberate misspelling (Xerox, Kodak, Spotify, Verizon)

```
                        CONSTRUCT
              Real-Word    Compound      Coined
                  ↓           ↓            ↓
            ┌──────────┬────────────┬──────────┐
  Abstract  │  Roku    │  YouTube   │  Xerox   │
            │  Apple   │  Snapchat  │  Kodak   │
     ↑      ├──────────┼────────────┼──────────┤
     │      │  Amazon  │  Airbnb    │ Spotify  │
Suggestive  │  Slack   │ Pinterest  │ Verizon  │
     │      ├──────────┼────────────┼──────────┤
     ↓      │  PayPal  │ Salesforce │Accenture │
Descriptive │  General │TripAdvisor │  (rare)  │
            │  Motors  │            │          │
            └──────────┴────────────┴──────────┘

APPROACH
```

### The Clarity vs. Creativity Spectrum

```
Descriptive ←────────────────── → Abstract
100% clarity                    100% creativity
0% creativity                   0% clarity

Sweet spot for most startups: Suggestive
(Netflix, Airbnb, Slack, Dropbox)
```

**Category guidance:**
- **Enterprise B2B:** Lean slightly descriptive (clarity builds trust faster)
- **Consumer lifestyle:** Lean suggestive to abstract (emotional pull matters more)
- **Deep tech / biotech:** Abstract + coined names signal innovation and protectability
- **Luxury:** Abstract real-words or invented names with phonosemantic prestige signals

## 4. Marty Neumeier's 8 Criteria

A great name must satisfy all eight:

| # | Criterion | Test Question |
|---|-----------|---------------|
| 1 | **Distinctive** | Does it stand apart from every competitor in this category? |
| 2 | **Brief** | Is it short enough to remember, type, and say without effort? |
| 3 | **Appropriate** | Does it fit the brand's personality and category conventions? |
| 4 | **Easy to spell** | Can customers find it online after hearing it once? |
| 5 | **Easy to pronounce** | Does it flow naturally when spoken? No stumbling? |
| 6 | **Likeable** | Does it create a positive first impression? |
| 7 | **Extendible** | Does it work across product lines, markets, and campaigns? |
| 8 | **Protectable** | Can it be trademarked and legally defended? |

**Scoring:** Each criterion is binary pass/fail. 7–8 passes = strong candidate. Below 6 = not viable without serious mitigation.

## 5. Catchword's 10 Touchstones

| # | Touchstone | What It Means in Practice |
|---|------------|--------------------------|
| 1 | Available | .com and social handles obtainable at reasonable cost |
| 2 | Trademarkable | Can be legally protected in the target category and market |
| 3 | Memorable | Sticks after one hearing; passes the next-day recall test |
| 4 | Scalable | Allows business expansion without changing the name |
| 5 | Short | Few syllables; easy to type on mobile |
| 6 | Positive Affect | Creates good feelings; avoids negative connotations |
| 7 | Good for SEO | Searchable without being so generic it drowns in noise |
| 8 | Easy to Pronounce | No stumbling; intuitive on first encounter |
| 9 | Easy to Spell | Phonetically maps to its spelling |
| 10 | Distinctive | Unique in the category; zero confusion with competitors |

**Scoring:** Weight touchstones 1 (Available) and 2 (Trademarkable) as eliminators — a name that fails either is not viable regardless of other scores. Score remaining 8 on 1–5 scale; maximum composite = 40.

## 6. Name Generation Techniques

**Key principle from Lexicon / David Placek:** Generate 1,000–3,000 raw candidates before evaluating. Quantity is not laziness — it is the only reliable method for finding gems because the promising names are buried in the mass.

### Techniques

1. **Three Words Method** — Each team member writes 3 words that must describe the brand. Combine, morph, and use as seeds.

2. **Syllable Recombination** — Take 5–10 relevant words, cut them into syllables, combine pairs and triplets randomly, then filter for phonosemantic alignment.

3. **Root Word Mining** — Excavate Greek and Latin roots that carry the right meaning. Used by Lexicon for Blackberry (brevity), Pentium (five + strength), Febreze (freshness from Latin "febris").

4. **Portmanteau Creation** — Blend two words that each carry half the brand story:
   - Pinterest = Pin + Interest
   - Microsoft = Microcomputer + Software
   - Snapchat = Snapshot + Chat
   Rule: the blend must be instantly decodable, not a cipher.

5. **Sound Symbolism First** — Start with the phoneme profile the brand needs, then work backward to words and invented words that carry those phonemes.

6. **Free Association Chains** — Idioms, proverbs, song lyrics, foreign words, mythology, geography, animal behavior. Work in long chains; the useful names are 10–15 associations away from the obvious starting point.

7. **Novel Spelling** — Phonetically equivalent spellings that look distinctive: Tumblr (Tumbler), Lyft (Lift), Fiverr (Fiver). **Caution:** Only proceed if the spelling passes the Search test — people must still find it online after hearing it.

8. **Metaphor Mining** — What phenomena from nature, physics, or culture carry the brand's emotional story? Slack (looseness, ease in a system), Amazon (vast and unexplored), Twitter (small sounds, constant chatter).

9. **Category Disruption** — What words are forbidden or unexpected in this category? Those are often the strongest candidates. Apple in computing. Monster in energy drinks. Innocent in juice.

10. **Language Borrowing** — Foreign words, transliterations, and cross-language blends that carry the right phonosemantic profile in English while holding cultural richness. Check for negative meanings in all major target-market languages.

## 7. The Professional Naming Funnel

```
Stage 1 — Wide Generation (1,000–3,000 candidates)
  Apply: Category disruption, root word mining, portmanteau, free association
  Filter: Nothing yet — quantity is the goal

Stage 2 — SMILE + SCRATCH Pass (→ 200–300)
  Apply: Alexandra Watkins framework
  Filter: Eliminate all SCRATCH flags; prioritize SMILE alignment

Stage 3 — Phonosemantic Alignment (→ 100–150)
  Apply: Sound symbolism table, phonosemantic scoring rubric
  Filter: Eliminate phonosemantic contradictions

Stage 4 — Naming Matrix Positioning (→ 50–75)
  Apply: Descriptive → Suggestive → Abstract × Real-Word → Coined
  Filter: Align with brand positioning and category norms

Stage 5 — Neumeier + Catchword Scoring (→ 30)
  Apply: 8 criteria + 10 touchstones
  Filter: Eliminate below threshold; flag availability killers

Stage 6 — Domain + Trademark Screening (→ 10–15)
  Apply: .com check, USPTO TESS / relevant national search
  Filter: Eliminate unavailable or conflicted names

Stage 7 — Presentation Set (5–7)
  Apply: Final strategic vetting, presentation rationale
  Deliver: Narrative, Naming Matrix position, phonosemantic brief, risk summary
```

## 8. Domain & Trademark Strategy

### Domain Priority Order
1. `[name].com` — always check first; highest commercial and trust value
2. `[name].io` — strong for tech/startup; widely understood signal
3. `[name].co` — viable alternative; growing legitimacy
4. `[name]app.com` — if product-focused and .com unavailable
5. `get[name].com` — action-oriented alternative
6. `[name].in` — required for India-first brands

### Social Handle Strategy
- Keep usernames under 15 characters for X/Twitter compatibility
- Check consistency across Instagram, LinkedIn, TikTok, YouTube
- Tools: **Namechk**, **BrandSnag**, **Knowem**
- If handles are inconsistent, choose the name variation that maximizes availability across the highest-value platforms

### Trademark Screening Protocol
1. Run USPTO TESS (us.gov) full-text search for the name
2. Search in the International Class(es) relevant to the product/service
3. Check EUIPO for EU exposure; check the national registry for each priority market
4. Flag: identical marks, phonetically similar marks, visually confusable marks
5. Recommend: exact availability is rare — the goal is "clear enough to proceed to legal review"

### Common Acquisition Strategies for Taken .com Domains
- Outbound offer via WHOIS owner (budget: 3–10x typical domain resale)
- Hyphenated version as bridge while negotiating (`get[name].com`)
- Country-code TLD (`.in`, `.co.uk`, `.de`) for geographic market launch
- Build brand on alternative extension (.io, .co) if domain holder is unreachable
- Never launch on a domain that could be confused with a competitor's

## 9. Phonosemantic Scoring Rubric

For each name, complete this rubric during internal evaluation:

```
Name: [Name]

Dominant phonemes: [List 2–3 key phonemes or classes]
Primary psychological signal: [What these phonemes subconsciously communicate]
Brand's target emotional territory: [What the brand needs the name to feel like]
Alignment score: [1–5]
  5 = The phonetics perfectly reinforce the brand's emotional promise
  4 = Strong alignment with minor friction
  3 = Neutral — phonetics neither help nor hurt
  2 = Slight contradiction — phonetics work against the brand position
  1 = Active contradiction — the phonetics sabotage the brand promise

Contradiction flags: [Name any specific phonemes that work against the brand]
Recommendation: [Keep / Modify / Eliminate]
```

## 10. Cultural & Linguistic Risk Checklist

Before finalizing any name, verify:

- [ ] Meaning in all major target-market languages (use native speaker verification, not machine translation alone)
- [ ] Slang or informal meanings in English (Urban Dictionary sweep)
- [ ] Phonetic similarity to offensive words in target-market languages
- [ ] Religious, political, or cultural associations in key markets
- [ ] Existing brand or product with the same name in adjacent categories globally
- [ ] Name behavior when spoken with regional accents (a name that sounds right in US English may be unpronounceable or comical in another English variety)
- [ ] Emoji / symbol associations if the name has a homophone with common emoji
- [ ] AI search and autocomplete behavior — does the name surface the right associations?

**High-risk categories for cultural missteps:** automotive, food & beverage, pharmaceutical, financial services, children's products.

**India-specific additions:**
- Check for caste, regional, or community associations
- Verify Sanskrit / Hindi root meaning (do not rely on AI — commission a native speaker review)
- Check for similarity to established Indian brands in the category
- Assess whether the name works in Hindi/regional language phonology (borrowing sounds that do not exist in Hindi creates pronunciation drift over time)
