## 1. Name Evaluation Scorecard

Use when scoring a shortlist of 3–10 names against SMILE, SCRATCH, Neumeier, and Catchword criteria.

```
BRAND NAMING EVALUATION SCORECARD
Brand: ___________________________
Category: ________________________
Date: ____________________________
Evaluator: _______________________

NAME: ___________________________

SMILE ASSESSMENT (5 qualities — mark each ✓ or ✗)
[ ] Suggestive — evokes something about the brand
[ ] Memorable — creates association with the familiar
[ ] Imagery — visually evocative
[ ] Legs — extends into broader brand mythology
[ ] Emotional — resonates positively with target audience
SMILE Score: ____ / 5

SCRATCH FILTER (7 deal-breakers — mark each ✓ if present = eliminate)
[ ] Spelling Challenged — looks like a typo
[ ] Copycat — sounds like existing brand
[ ] Restrictive — limits future category growth
[ ] Annoying — forced or precious wordplay
[ ] Tame — flat, uninspired, purely descriptive
[ ] Curse of Knowledge — meaningful only to insiders
[ ] Hard to Pronounce — people will avoid saying it
SCRATCH Flags: ____ / 7  → 1+ flag = investigate; 2+ = eliminate

PHONOSEMANTIC PROFILE
Dominant phonemes: _______________
Signal: _______________
Alignment with brand territory (1–5): ___

NAMING MATRIX POSITION
Approach:   [ ] Descriptive  [ ] Suggestive  [ ] Abstract
Construct:  [ ] Real-Word    [ ] Compound    [ ] Coined

NEUMEIER 8 CRITERIA (pass/fail each)
[ ] Distinctive    [ ] Brief          [ ] Appropriate
[ ] Easy to spell  [ ] Easy to say    [ ] Likeable
[ ] Extendible     [ ] Protectable
Neumeier Score: ____ / 8

CATCHWORD 10 TOUCHSTONES (rate 1–5 each; 1=fail, 5=excellent)
Available (domain/TM): ___   Trademarkable: ___   Memorable: ___
Scalable: ___   Short: ___   Positive affect: ___
SEO: ___   Pronounce: ___   Spell: ___   Distinctive: ___
Catchword Score: ____ / 50

DOMAIN & AVAILABILITY
.com available: [ ] Yes  [ ] No  [ ] Purchase required ($____)
.io available:  [ ] Yes  [ ] No
Social handles: [ ] Consistent  [ ] Inconsistent  [ ] Unavailable
Trademark conflict: [ ] None  [ ] Minor  [ ] Major conflict

OVERALL ASSESSMENT
Overall score: ____ / 10
Recommendation: [ ] Strong candidate  [ ] Viable with mitigation  [ ] Eliminate
Key strength: _______________
Key risk: _______________
Notes: _______________
```

## 3. Name Candidate Table

Use when presenting a shortlist of name options with comparative scoring.

```markdown
| Name | Type | Core Meaning | SMILE | SCRATCH Flags | Neumeier | Catchword | .com | TM Risk | Overall |
|------|------|-------------|-------|---------------|----------|-----------|------|---------|---------|
| [Name] | Descriptive/Suggestive/Abstract × Real/Compound/Coined | [Brief meaning] | [X/5] | [n flags] | [X/8] | [X/50] | [Y/N/$] | Low/Med/High | [X/10] |
```

**Instructions:**
- List names in order of overall score, highest first
- Include all candidates that survived SCRATCH filtering
- Add a "Recommendation" row at the bottom highlighting the top pick
- Color-code SCRATCH flags: 0 flags = green, 1 = yellow, 2+ = red

## 7. Output Validation Checklist

Run before delivering any naming output to the user.

```
OUTPUT VALIDATION CHECKLIST

GENERATION MODE — verify before delivering:
[ ] Strategy brief written before any names generated
[ ] Names generated across 3+ distinct strategic directions
[ ] Every name passed mental SMILE test before inclusion
[ ] Every name passed SCRATCH filter — no unexamined flags
[ ] Phonosemantic profile considered for each name
[ ] Naming Matrix position identified for each name
[ ] Evaluation Table populated with all candidates
[ ] Top 5 clearly ranked with one-line rationale
[ ] Single strategic recommendation with mechanistic reasoning
[ ] Pre-Finalization Checklist included
[ ] No AI-sounding template names included (Nexa, Vanta, Zyra, etc.)
[ ] No overused suffixes included unless strategically justified

EVALUATION MODE — verify before delivering:
[ ] Brand context confirmed before evaluation
[ ] Every provided name evaluated against full framework
[ ] SMILE + SCRATCH scores provided per name
[ ] Phonosemantic profile included per name
[ ] Neumeier 8 and Catchword 10 scores provided
[ ] Domain / TM risk flagged per name
[ ] Clear ranking from strongest to weakest
[ ] Single direct recommendation with reasoning

TONE CHECK:
[ ] No flattery of weak names
[ ] All weaknesses named directly
[ ] Recommendation is decisive — not hedged
[ ] Language is human, not templated
```
